Vice Panel Studio is a GTA-style cover art maker that runs entirely in the browser: drop in your own photos, arrange them across six slanted multi-panel poster layouts, push them through five per-pixel colour grades (Sunset Strip, Neon Nights, Golden Hour, Vice Pastel, Midnight Noir), and finish the poster with film grain, a vignette or halftone dots under a bold gradient masthead with a script subtitle, the studio's own rating badge and a barcode. Every panel can be reframed by dragging and zooming, the words are all editable, and the finished cover exports as a PNG at 1080 × 1080, 1080 × 1350 or 1920 × 1080. It is a single static app — no build step, no network, no dependencies — with its type set in the open-licensed Anton and Pacifico fonts.

## Run it

```sh
node serve.ts
```

Then open the local address it prints (http://localhost:8080) in a browser.
